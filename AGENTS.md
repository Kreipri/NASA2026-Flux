# Agent Instructions

Project: NASA Space Apps 2026, Junior Astronaut Mission Trainer (kids 7-12, survival resource-management game).

## Start here
1. `CONTEXT.md`: the brief and our direction.
2. `DECISIONS.md`: what's decided, proposed, and open. Don't reverse decisions silently.
3. `HANDOFF.md`: current state and next steps.

## Working rules
- We're in **ideation**. Default to concise text, bullets, and ASCII wireframes. Don't build code, HTML, or design files unless asked.
- Give 3-5 distinct options, recommend one, and name the trade-offs. Push back on weak ideas.
- Hard constraints from the brief: no free choices, 2-3 core resources, plain language for ages 7-12, real NASA data clearly attributed, never present static data as live.
- Original art and mascot only. Don't copy Fallout or other IP.
- Save work to files (`ideas/` for drafts), log decisions in `DECISIONS.md`, and update `HANDOFF.md` before you stop.
- Don't spawn subagents or large workflows unless asked.
