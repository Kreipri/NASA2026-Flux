# AI assistance disclosure

Project: Space Base Commander. Team: The Space Flux (Bea Margaret B. Ganotisi and Neo F. Mariñas).

Bea created the layout wireframe, original Curio vector design and selected other vector graphics. AI tools including Codex and Claude assisted with workflow, design alternatives, software implementation/debugging, research navigation, text drafting and other vector/3D/code artwork under human direction. Team membership does not itself establish individual authorship of every asset.

No new text-to-image generation was used to create the final vector production assets or this submission deck. AI-authored SVG/code graphics are still disclosed as AI-generated artwork. A historical, unapproved raster concept sheet documented in `ideas/character-designs/README.md` is excluded from the shipped game and submission deck. Do not erase or misrepresent that development history.

The game runs authored guidance and deterministic rules, not a live language model. NASA archive observations retain original provider attribution. AI-assisted processing code produces derived summaries, which are distinct from the source measurements. Simulated resource costs/exposure points are game rules.

Machine-readable metadata is shipped as `ai-disclosure.json`. Visible notices identify AI-generated artwork in the game/deck. Generated content must not imitate NASA logos, flags or mission identifiers. We make no claim of NASA endorsement or certified educational effectiveness.

Organizer guidance: https://github.com/nasa/spaceapps/discussions/1849 (GO Team: images/video require a visible AI-generation watermark; code/data require descriptive text and metadata). Applying artwork disclosure to generated vectors is a conservative production choice; no vector exemption is claimed.
