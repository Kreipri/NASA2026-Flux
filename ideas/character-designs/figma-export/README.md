# Figma export (generated)

54 SVGs, one character or version per file, transparent background, 200×240 canvas (faces 120×120, heads 200×170). Generated by `../chibi-v4/build.mjs`; re-run it to regenerate. Don't hand-edit these.

**Import:** drag the files (or whole folders) onto a Figma canvas. Each one becomes an editable vector frame.
- Layers are named: `tail`, `legs`, `body` / `suit-body`, `head` / `helmet`, `arms` / `arm-left` / `arm-right`, `prop`, `wheels` / `feet`, `extras`.
- Clip paths (vests, visor window, robot body shading) come in as masks.
- The "?" bubble on `curio-*-explaining` is live text in Nunito; install Nunito or outline it.

**Folders**
- `crew/`: Bram, Remy, Commander × clothes (`polo`, `hoodie`, `role`) + suits (`bubble`, `visor`, `colour`).
- `mica/`: the three species options (`cat`, `tortoise`, `monkey`) × the same 6 outfits + a head-only file.
- `curio/`: robot options (`wheel-feet`, `wheels`, `legs`) × `happy` / `explaining` / `cheering`; `faces/`: 6 screen faces.
