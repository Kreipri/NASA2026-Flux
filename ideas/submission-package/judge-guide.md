# Space Base Commander — judge quick-start

The Space Flux: Bea Margaret B. Ganotisi and Neo F. Mariñas.

A browser game for ages 7–12 about planning work at a fictional Moon base. The learning goal is that where you work changes the available sunlight, power and radiation risk.

1. Open the public play URL in RELEASE.md. No game account or installation is required.
2. Start the story and follow Curio into the guided first week. The dust-clearing introduction is guided; it is not presented as a strategic two-option decision.
3. Open a job and inspect its crew-time and resource costs. Run the air system to exchange power for air, or inspect an outside job later in the mission to compare exploration cost with shelter time.
4. Read the job result. At End week, inspect the recap, which separates jobs from weekly changes.
5. Open More → NASA data and game rules. Historical observations have archive dates; meter values and weekly hazard points are simulated. Title-screen Real NASA data and ending source cards also link the science.
6. Continue through the mission and inspect the report card and final story. Replay with a different plan, or try Solar max.

The game saves locally in this browser. More → Reset all data erases the mission. Browser storage settings can prevent saving.

NASA contribution: archived DONKI event context and CRaTER/LRO lunar-orbit radiation measurements through RadLab, plus NASA lunar science. Measurements are not readings at the fictional surface base. Learning gains have not been measured through formal child testing. Runtime AI-written events and Mars gameplay are future work.
