# Title screen drafts v1 (proposed, 2026-11-14)

Based on Bea's Pinterest board "Space flux" (23 pins). Only the mood is borrowed; no layouts, characters or logos copied.

## What the board has in common
- Flat vector with **soft gradients and rim light**: glowing planet edges, 4-point sparkles, comet streaks.
- **Big sky, low camera, tiny cozy scene** (campfire + tent, island base, tower).
- **Rounded, friendly shapes**: chunky pill buttons, rounded bubble type or clean wide geometric sans.
- **One warm light against a cool night** (campfire orange, gold coin, sun glow on navy).
- Game menus: one big round Play button, level paths with locked nodes, a mascot speaking from a portrait.
- Mostly violet/indigo, with teal/mint and navy boards as the alternatives.

**Palette adjustment:** D-023 says no violet, so the board's purple becomes **deep navy into blue-indigo at the very top of the sky**. The pop comes from **warm amber (habitat light) and soft teal (Earth, UI)** instead. Real purple would need an exception for the title and story screens only (open question below).

All drafts keep the existing pieces: working title "Mission: Outpost", Mission 1 · Moon, locked Mission 2 · Mars, Settings, "Uses real NASA data", Data sources.

## A. Lamp on the Ridge (cozy night scene) — **recommended**
Low camera on the ridge. The habitat is the only warm light; the crew of 4 and Base Bot stand in its glow. Earth hangs low on the horizon. Huge starry sky with a soft gradient, slow sparkle twinkle.
```
┌──────────────────────────────────────────────────────────────┐
│ ✦        ·          M I S S I O N : O U T P O S T      ·     │
│    ·          Junior Astronaut Training                ✦     │
│                                                              │
│       ✦            ·                        ◐ Earth          │
│   ▁▂▃▄▃▂▁                       ▄▀▀▄  ░warm glow░           │
│ ▁▂▃▄▅▆▅▄▃▂▁▁▂▃▂▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁ █▓▓█  ☺☺☺☺ 🤖 ▁▁▁▁▁▁▁▁▁▁▁▁▁ │
│                                                              │
│      ( ▶ Mission 1 · Moon )    ( 🔒 Mission 2 · Mars )        │
│  ⚙ Settings              Uses real NASA data · Data sources │
└──────────────────────────────────────────────────────────────┘
```
- **Why:** the art already says the lesson: light is warmth and safety, darkness is the danger. It matches the campfire reference used for the base screen, so the cut into the 3D base feels natural.
- **Trade-offs:** calm, not loud. Needs a good silhouette of the crew and bot at small size. Title must sit on a scrim (taste fix #7).
- **Risk:** a fully dark scene contradicts "sunlit most of the year". Fix: low sun on the horizon behind the ridge (twilight), not night.

## B. Moon Slice Diorama (floating cut-away)
A floating slice of the south pole, like a cake wedge: sunny ridge on top with the base, and a cut-away side showing a dark crater with an ice glint deep inside. It turns slowly. Chunky rounded logo above.
```
┌──────────────────────────────────────────────────────────────┐
│                 ╭ MISSION: OUTPOST ╮   ✦                     │
│   ☀ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐                                    │
│                ▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄  ← sunlit ridge, tiny base    │
│               ███████▀▀▀▀▀█████                              │
│                ▀████  ❄  ████▀   ← shadowed crater, ice?     │
│                   ▀▀█████▀▀                                  │
│           ( ▶ PLAY )        Mission 2 · Mars 🔒              │
│  ⚙                               Real NASA data · Sources    │
└──────────────────────────────────────────────────────────────┘
```
- **Why:** teaches sunlit vs shadowed ground at a glance, before any text.
- **Trade-offs:** most illustration work. Floating rock is clearly not real; fine on a title, but it needs the "art, not a map" feel.
- **Risk:** cut-away suggests we know where the ice is. Keep the glint as a "?" sparkle (ice is uncertain).

## C. Training Path (mission map)
A dotted path across the sky: Earth (Training done ✓) → Moon (glowing, big round Play button) → Mars (locked padlock). Base Bot pops up from a corner portrait with one line.
```
┌──────────────────────────────────────────────────────────────┐
│  MISSION: OUTPOST                               ⚙            │
│                                                              │
│   ◐ Earth ✓ · · · · · · · ( ● ▶ ) · · · · · · · · ○ Mars 🔒  │
│                          Mission 1                Mission 2  │
│                          The Moon                 Coming soon│
│  ┌──┐                                                        │
│  │🤖│ "Ready, cadet? First stop: the Moon's south pole."     │
│  └──┘                                Real NASA data · Sources│
└──────────────────────────────────────────────────────────────┘
```
- **Why:** clearest for 7-year-olds (one obvious button), and the Mars tease is built in. Cheapest to build.
- **Trade-offs:** looks like many kids' apps, less memorable. Says little about the lesson.
- **Risk:** a flight path suggests launch/travel gameplay we don't have. Label nodes as "training missions" and fade, don't fly, between them.

## D. Bubble Logo + Base Bot (loud mascot hero)
Big rounded gradient bubble-letter logo with a small Moon dotting the "O". Base Bot floats in front, waving and holding a mission patch. Planets, comets and sparkles all around.
```
┌──────────────────────────────────────────────────────────────┐
│   ○          ✦          ·               ◑                    │
│        ╭━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╮      ☄             │
│        ┃   M I S S I O N : O U T P ◐ S T  ┃                  │
│        ╰━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╯                    │
│                     \🤖/ [patch]                             │
│                  ( ▶  START MISSION )                        │
│   ⚙                                 Real NASA data · Sources │
└──────────────────────────────────────────────────────────────┘
```
- **Why:** most energy and the strongest "this is a game" first impression. Makes the mascot the brand.
- **Trade-offs:** needs a finished mascot and a logo first (both still TBD). Generic floating planets don't say "south pole".
- **Risk:** closest to the board's stock kids-app look and the easiest to make purple. May feel too young for 10-12.

## E. Visor Reflection (personal, astronaut-ID)
Close-up of a helmet visor. The ridge, the Sun and Earth reflect in it. Below it is a suit name tag: "JUNIOR ASTRONAUT ____". Typing a name (or skipping) starts the mission.
```
┌──────────────────────────────────────────────────────────────┐
│                       ╭───────────╮                          │
│                     ╭─┤ ☀  ◐ Earth├─╮   MISSION: OUTPOST      │
│                     │ │ ▁▂▃▄▃▂▁▁ ⌂ │ │                         │
│                     ╰─┤  (visor)  ├─╯                         │
│                       ╰───────────╯                          │
│              ┌ JUNIOR ASTRONAUT [ type your name ] ┐         │
│                     ( ▶ Suit up )   Skip                     │
│  ⚙                                  Real NASA data · Sources │
└──────────────────────────────────────────────────────────────┘
```
- **Why:** puts the kid in the role from the first second, and the name can feed the ending praise (storyline v1).
- **Trade-offs:** a typing step adds friction for young kids. A reflection in a curved visor is hard to do well in flat vector.
- **Risk:** a name field on a school Chromebook raises privacy questions. Keep it local only, never sent anywhere, and optional.

## Recommendation
**A, with C's two mission buttons** (already in the current spec). It's the only draft where the picture carries the teaching point. It reuses the low-camera campfire look Bea already picked, and it's cheap to make: a few silhouettes, a gradient sky, one glow. Borrow E's optional name tag later if the ending praise uses the player's name.
